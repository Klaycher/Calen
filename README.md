# Расписание 1Б • Юридический факультет БГУ (Модульная архитектура v1.0)

Веб-приложение координатора сессии и справочника преподавателей для специальности «Политология» (4 курс, заочное отделение, группа 1Б).

## 📂 Модульная структура проекта

```text
├── index.html              # Чистый каркас интерфейса и модальных окон (без громоздкого JS)
├── css/
│   └── style.css           # Стили, адаптивная сетка календаря и стеклянные карточки
├── data/
│   ├── schedule.json       # Живая база расписания пар, зачётов/экзаменов, смен и лога
│   ├── teachers.json       # База 15 преподавателей Юрфака БГУ (биографии, фото, контакты)
│   └── releases.json       # История обновлений приложения (v0.1 – v1.0)
└── js/
    ├── config.js           # Константы, глобальное состояние, утилиты дат и загрузчик JSON
    ├── calendar.js         # Сетка 21 дня, лента дней, сводка «На данный момент» и пуши
    ├── teachers.js         # Поиск, фильтрация и карточка досье преподавателя
    ├── admin.js            # Пароль администратора (4778), CRUD событий и журнал истории
    ├── github-sync.js      # Чтение/запись в GitHub API и точечное обновление любого модуля
    ├── ai-scanner.js       # Подключение Gemini API, распознавание фото стенда и слияние
    └── app.js              # Установка PWA на телефон, запуск таймеров и инициализация
```

## 🚀 Как развернуть в новом репозитории GitHub

### Способ 1: Авто-развёртывание в 1 клик прямо из приложения
1. Создайте новый публичный репозиторий на GitHub (например, `raspisanie-v2`), отметив галочку **Add a README file** (чтобы сразу создалась ветка `main`).
2. Откройте окно **«🧩 Модули (13)»** в шапке приложения.
3. Введите имя репозитория (`ваш-логин/raspisanie-v2`) и ваш GitHub Personal Access Token, затем нажмите **«🚀 Развернуть все 13 модульных файлов в репозиторий GitHub»**.
4. В настройках репозитория на GitHub откройте **Settings ➔ Pages** и выберите ветку `main` (`/root`).

### Способ 2: Загрузка из архива `raspisanie-1b-modular.zip`
1. Распакуйте архив `raspisanie-1b-modular.zip` на компьютере.
2. Перетащите все файлы и папки (`index.html`, `css/`, `data/`, `js/`) в окно загрузки вашего нового репозитория на GitHub и нажмите **Commit changes**.

## 🛠️ Как обновлять отдельные блоки

Вам больше не нужно переписывать всё приложение целиком:
- Чтобы обновить расписание — используйте админку (пароль `4778`), она сама сохраняет изменения в `data/schedule.json`.
- Чтобы обновить логику конкретного блока (например, только календарь `js/calendar.js` или сканер `js/ai-scanner.js`) — откройте в админке **«🔄 Обновить базу» ➔ «Точечное обновление любого модуля»**, выберите нужный `.js`-файл и нажмите **«🚀 Запушить выбранный модуль на GitHub»**.
