Gemini API
Источник: law.bsu.by (Первое высшее и параллельное образование). В демо-режиме Gemini создаёт случайное расписание в файле demo.html в репозитории, ждёт его записи, считывает изменения и запрашивает подтверждение (само расписание не меняется, а demo.html удаляется).
✨ Умное подключение Gemini v0.7: приложение само запрашивает у Google список всех моделей, доступных на твоём ключе, и автоматически переключается на свободную модель, если основной сервер перегружен.

Бесплатный ключ берётся на aistudio.google.com/apikey (сохраняется в браузере автоматически)

Установка как приложение

Открывай расписание в 1 клик с иконки на экране

✨ Работает без адресной строки и вкладок: как полноценное приложение на весь экран, сохраняет всё расписание в памяти и открывается даже без интернета!
🤖 Для Android (Chrome / Яндекс / Samsung):

1. Нажми меню из трёх точек ⋮ в правом верхнем углу браузера.
2. Выбери пункт «Установить приложение» (или «Добавить на главный экран»).
3. Нажми «Установить» — иконка «1Б» появится на рабочем столе телефона!

🍏 Для iPhone / iPad (Safari):

1. Открой сайт в браузере Safari.
2. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх ⎋ внизу экрана).
3. Прокрути вниз и нажми «На экран "Домой"» (значок с плюсом ➕).
4. Нажми «Добавить» — сайт станет отдельным приложением без рамок Safari!
